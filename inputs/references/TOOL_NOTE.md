# Available implementation documentation

Installed Python API documentation is available through Python help. The environment includes RDKit for molecular graphs, descriptors and coordinate operations; scikit-learn for simple statistical models; and an open-source molecular renderer. Inspect actual imports and versions rather than assuming the older project notebook describes the current interface. A documented feature is not proof that the particular operation or scientific interpretation is correct.

Official reference index: https://www.rdkit.org/docs/ ; https://scikit-learn.org/stable/ ; https://pymol.org/ . The supervisor freezes the local environment and makes its installed documentation available before launch. Scientific web access is disabled during this run. A movie, proprietary license, or new connector is not mandatory.
