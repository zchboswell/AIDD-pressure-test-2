`assay_math.py` exposes `normalize(value, unit, relation='=', endpoint='IC50')`. Preserve this callable in the repaired copy `analysis/assay_math.py` for downstream compatibility. A successful output is a dictionary with status `ok`, endpoint, value_nm, relation_nm, p_activity, and p_relation. A rejected input returns status `invalid` and a reason. The supported concentration units are nM, uM, µM, μM, mM and M; concentration comparisons are =, <, <=, > and >=, including ≤ and ≥ aliases. IC50, Ki and Kd remain distinct quantities. Missing, nonpositive, nonfinite, unsupported-unit and unsupported-relation inputs cannot produce valid logarithmic activities. An unsupported endpoint is rejected rather than relabeled.
