# Scientific review standards

The same rubric applies to every submission. Fifty is competent acceptance; 100 requires exceptional, demonstrated decision value. Routine correctness does not automatically earn full marks. Reported skill use, capture schemas, model complexity, number of commits, and volume of files do not earn scientific-quality points.

| Area | Weight |
|---|---:|
| Scientific identity and evidence semantics | 15 |
| Valid analysis and discriminating verification | 15 |
| Useful, feasible compound prioritization | 15 |
| Effective next experiment/action | 15 |
| Uncertainty characterization | 10 |
| Information value and decision restraint | 10 |
| Reproducible scientific result | 5 |
| Practical scientific handoff | 5 |
| Decision communication | 5 |
| Claim fidelity and transparency | 5 |

Each criterion receives 0%, 25%, 50%, 75% or 100% of its weight. Half-weight means the competent expected outcome is present; exceptional credit needs stronger evidence that improves a consequential decision or its practical use. Two independent reviewers score deidentified scientific packets using fixed anchors and independent checks. Material scientific false claims that would mislead the decision veto acceptance regardless of the numerical total. Truthful abstention can be excellent work when it still delivers a useful, feasible next action. Missing work is not the same as justified abstention.

Execution completion, capture completeness, resource costs and repository traceability are reported separately. The analysis is not rewarded for producing a positive conclusion about any tool or method.
