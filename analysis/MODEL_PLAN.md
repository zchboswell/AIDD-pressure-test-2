# Frozen audit protocol (before model evaluation)

Decision: prospective cellular CDK2 engagement with a useful CDK1 window. No supplied approved model predicts this endpoint. Candidate predictions table will report traceable SIM-TE-01 observations where identity is valid, and abstain for missing measurements. No historical biochemical prediction will be relabeled cellular engagement.

Curation: exact positive public IC50 in CHEMBL5736732, source-record reconciled, valid graph, one representative per source_activity_id, is the only eligible exploratory historical-label cohort. Its multi-kinase source description does not identify the row's CDK2 cyclin/ATP unequivocally; it is an assay-export endpoint, not proven comparable to new CDK2-E1 at1mM ATP. Censored values remain bounds/context, other assays/endpoints remain separate, invalid chemistry/units/nonpositive values are quarantined. Potential_duplicate alone does not establish reingestion. Canonical isomeric SMILES preserve stereo, isotopes, charges and disconnected components; no inferred parent or tautomer merging.

Audit: preserve original vendor script execution with original helper. Compare fixed RF(80 trees,seed7,n_jobs1) using the supplied retrospective activity index versus its three structure-derived descriptors. On the curated cohort use common five-fold Murcko scaffold groups when >=5 distinct groups; otherwise leave-one-scaffold-out if >=2, otherwise no extrapolation evaluation. Keep exact chemical and chosen-fingerprint collision groups together, unioned with scaffold groups if necessary. No tuning, no external data, no author-blind or temporal claim. Primary predictions are out-of-fold across these groups. Report pooled MAE/RMSE/R2 and fold errors; folds are not independent experiments. Save cross-partition maximum Morgan similarity.

Credible controls: training-only mean and one-nearest-neighbor Morgan radius2/2048/chiral Tanimoto. Diagnostic RF with retrospective index exposes leaked-label performance, not a deployable alternative. Fixed-label-shuffle negative control for the descriptor RF (20 independent seeds at chemical-unit level; skip if conflicting repeated observations preclude unit definition). This is a sanity check, not a fitted p-value for cellular utility. No performance threshold will license cellular inference from a biochemical assay. No calibrated prediction intervals without matched independent calibration evidence.

Sampling limits: related patent compounds, bounded observations excluded from exact regression, incomplete source dose-range and cyclin mapping, selection bias and uncertain experimental independence. Any model failure or post-result modification is retained and treated as development, not pristine validation.

Pre-fit curation inspection: 122 eligible rows represent117 full chemical graphs and26 Murcko scaffolds; largest scaffold has66rows. Five graphs have distinct source activities with differing labels (maximum spread1.538273log). Keep these observations and source IDs separate and grouped; do not silently infer experimental replication or equal activity. Score each chemical with total weight1, dividing across its rows; RF training and mean baseline use these weights. Nearest-neighbor reference is the arithmetic mean log label of the nearest training chemical, with its replicate ambiguity disclosed. The planned chemical-unit label shuffle is omitted because conflicting repeated activities plus unresolved assay-row cyclin context do not supply a unique experimentally defined permutation unit. No biological-model acceptance claim depends on a null control. Use common scaffold folds as exploratory evidence, with fold sizes and similarity exposed.
