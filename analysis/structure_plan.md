# Frozen structural audit scope
The question is whether the supplied vendor exports preserve the 1H1Q chain-A 2A6 binding-site relationship. Original SDF heavy atoms and receptor frame are immutable. No fitting, hydrogen addition, minimization, docking or coordinate repair is allowed in the primary export assessment. Compare complete graph isomorphisms preserving element/isotope/charge/H-count/aromatic bonds/stereochemistry (RDKit sanitized representation); reject absent/incomplete maps. Enumerate at most 100,000 matches, fail if limit reached. Fixed-frame RMSD is the minimum unweighted heavy-atom coordinate RMSD in Å across mappings. A 0.001 Å maximum per-atom preservation tolerance reflects file serialization only. A 2 Å pose-recovery diagnostic is secondary; failure of exact frame preservation prohibits treating an export as the deposited complex. Ligand-only aligned shape RMSD, if reported, is explicitly secondary and cannot rescue frame failure.

Independent checks: raw SDF coordinate parser and scalar sum-of-squares cross-check mapped NumPy and RDKit CalcRMS; unchanged identity, valid atom renumbering, common rigid transform, ligand-only [5,0,0] Å displacement, state change and incomplete map. Keep installed API documentation with observed version/path. Assess reference-to-PDB atom coordinates and component identity before candidate outputs. Geometry scope is finite coordinates, mapped bond-length conservation, ligand-protein minimum distance and enumerated heavy-atom polar proximity <=3.5 Å; no full energetic/experimental validation claimed. Missing maps/local electron-density evidence constrain interpretation.

Render fixed source coordinates with nearby waters and site residues retained. Cartoon contextual views may hide distal atoms only for display; no molecular source deletion. At least one view must show the uncorrected priority displacement in the same receptor frame. Static images sufficient; no simulated dynamics or affinity inference. Stop if identity fails or numerical controls fail; retain failures. One leased CPU thread, <=1 GiB planned.
